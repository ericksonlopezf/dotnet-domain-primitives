# Level 2 — Full Configuration

This level covers global assembly-level configuration, dual serialization (`System.Text.Json` and `Newtonsoft.Json`), and NativeAOT-safe Smart Enums.

---

## 1. Global Assembly-Level Configuration

Using `[assembly: DomainPrimitivesDefaults]`, you can enforce organizational conventions and default invariants across all domain primitives in the compilation:

```csharp
using EricksonLopez.DomainPrimitives;

// Global assembly-wide default invariants
[assembly: DomainPrimitivesDefaults(
    Trim = true,
    NotEmpty = true,
    MaxLength = 250
)]
```

### Precedence Rules
Type-level declarations always override assembly-level defaults:
- If the assembly declares `MaxLength = 250`, but a primitive is decorated with `[MaxLength(500)]`, `500` takes precedence.
- If a semantic shortcut like `[PasswordHash]` is used, its intrinsic rules govern.

## 2. Serialization: System.Text.Json and Newtonsoft.Json

### System.Text.Json (Reflection-Free, Native)
Every primitive generated by the source generator automatically includes an inline converter for `System.Text.Json` that serializes the primitive directly as its scalar value:

```csharp
var customer = new CustomerRecord(CustomerId.New(), CustomerEmail.Create("user@example.com"));

// Serializes to: {"Id":"...","Email":"user@example.com"}
string json = JsonSerializer.Serialize(customer);
```

### Newtonsoft.Json (Legacy Support)
For legacy projects requiring `Newtonsoft.Json`, the `EricksonLopez.DomainPrimitives.NewtonsoftJson` bridge package provides transparent support:

```csharp
using EricksonLopez.DomainPrimitives.NewtonsoftJson;

var settings = new JsonSerializerSettings()
    .AddDomainPrimitives();

string legacyJson = JsonConvert.SerializeObject(customer, settings);
```

Alternatively, register the contract resolver globally:

```csharp
settings.ContractResolver = new DomainPrimitivesContractResolver();
```

## 3. NativeAOT-Safe Smart Enums

Traditional reflection-based smart enums fail under NativeAOT compilation. With `[SmartEnum<TValue>]`, the Roslyn source generator generates the static catalog at compile time:

```csharp
using EricksonLopez.DomainPrimitives;

[SmartEnum<int>]
public readonly partial record struct OrderStatus
{
    public static readonly OrderStatus Pending = new(1, nameof(Pending));
    public static readonly OrderStatus Processing = new(2, nameof(Processing));
    public static readonly OrderStatus Completed = new(3, nameof(Completed));
    public static readonly OrderStatus Cancelled = new(4, nameof(Cancelled));
}
```

### Generated Capabilities
- `OrderStatus.All`: Read-only list of all declared enum instances.
- `OrderStatus.FromValue(int value)` / `TryFromValue(...)`: O(1) lookup by numeric value.
- `OrderStatus.FromName(string name)` / `TryFromName(...)`: Case-insensitive name lookup.
- `status.Match(...)`: Exhaustive compile-time pattern matching.
