# DP0008: Value object properties must use init

| Property | Value |
| :--- | :--- |
| **Rule ID** | DP0008 |
| **Category** | Correctness |
| **Default Severity** | Error |
| **Enabled by Default** | 	rue |

## Description

All properties of a [ValueObject] must use get; init; to guarantee immutability.

## How to Fix

Follow the diagnostic message guidance to ensure your domain primitives adhere to the zero-allocation, immutable, and type-safe architecture.
