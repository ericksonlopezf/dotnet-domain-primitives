# DP0007: Avoid uninitialized domain primitive

| Property | Value |
| :--- | :--- |
| **Rule ID** | DP0007 |
| **Category** | Design |
| **Default Severity** | Warning |
| **Enabled by Default** | 	rue |

## Description

Avoid using the default constructor for domain primitives. Instantiate via Create() or TryCreate() to ensure validation rules run.

## How to Fix

Follow the diagnostic message guidance to ensure your domain primitives adhere to the zero-allocation, immutable, and type-safe architecture.
