# DP0012: Public constructor bypasses validation

| Property | Value |
| :--- | :--- |
| **Rule ID** | DP0012 |
| **Category** | Design |
| **Default Severity** | Warning |
| **Enabled by Default** | 	rue |

## Description

Declaring a public constructor bypasses source-generated validation. Use the generated Create() factory pattern.

## How to Fix

Follow the diagnostic message guidance to ensure your domain primitives adhere to the zero-allocation, immutable, and type-safe architecture.
