# DP0010: String compared directly with domain primitive

| Property | Value |
| :--- | :--- |
| **Rule ID** | DP0010 |
| **Category** | Performance |
| **Default Severity** | Warning |
| **Enabled by Default** | 	rue |

## Description

Comparing a raw string directly to a domain primitive bypasses the type system. Parse into the primitive type first.

## How to Fix

Follow the diagnostic message guidance to ensure your domain primitives adhere to the zero-allocation, immutable, and type-safe architecture.
