# DP0013: Possible duplicate domain primitive logic

| Property | Value |
| :--- | :--- |
| **Rule ID** | DP0013 |
| **Category** | Design |
| **Default Severity** | Info |
| **Enabled by Default** | 	rue |

## Description

Two or more domain primitives share identical attribute configuration. Verify distinct domain intent.

## How to Fix

Follow the diagnostic message guidance to ensure your domain primitives adhere to the zero-allocation, immutable, and type-safe architecture.
