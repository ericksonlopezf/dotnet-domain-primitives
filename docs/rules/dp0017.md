# DP0017: Invalid DomainPrimitivesDefaults ExceptionType

| Property | Value |
| :--- | :--- |
| **Rule ID** | DP0017 |
| **Category** | Correctness |
| **Default Severity** | Error |
| **Enabled by Default** | 	rue |

## Description

Custom validation exception types specified in [assembly: DomainPrimitivesDefaults] must derive from Exception.

## How to Fix

Follow the diagnostic message guidance to ensure your domain primitives adhere to the zero-allocation, immutable, and type-safe architecture.
