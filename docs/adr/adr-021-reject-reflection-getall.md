# adr-021: Reject Reflection-Based GetAll() for SmartEnum

**Date:** 2026-08-10
**Status:** Accepted
**Authors:** Core maintainers
**Related audit items:** REJECT-001 (feature-gaps.md)

---

## Context

`Ardalis.SmartEnum` — the dominant SmartEnum library — implements `GetAll()` using reflection:

```csharp
// Ardalis.SmartEnum pattern (reflection-based, AOT-unsafe):
public static IReadOnlyCollection<TSmartEnum> List()
    => typeof(TSmartEnum)
        .GetFields(BindingFlags.Public | BindingFlags.Static | BindingFlags.DeclaredOnly)
        .Where(f => f.FieldType == typeof(TSmartEnum))
        .Select(f => f.GetValue(null))
        .Cast<TSmartEnum>()
        .ToList()
        .AsReadOnly();
```

This pattern has documented AOT/trimmer issues — the trimmer cannot statically analyze which
fields are accessed by `BindingFlags.DeclaredOnly` across assemblies.

`EricksonLopez.DomainPrimitives` generates a static readonly array instead:

```csharp
// Generated by SmartEnumGenerator.cs (source-generated, AOT-safe):
public static readonly IReadOnlyList<OrderStatus> All =
    new[] { Pending, Shipped, Delivered };

public static IReadOnlyList<OrderStatus> GetAll() => All;
```

---

## Decision

**`EricksonLopez.DomainPrimitives` will never add a reflection-based `GetAll()` variant.**

The source-generated static array is the only supported implementation. This decision is
permanent and not subject to reconsideration unless Native AOT is deprecated from .NET.

---

## Rationale

### 1. Native AOT compatibility is a first-class requirement

The library's CI pipeline includes a `dotnet publish -p:PublishAot=true` gate that must pass on
every commit. Reflection-based member enumeration (`GetFields`, `GetProperties`) triggers
`IL2072` / `IL3050` trimmer warnings and is incompatible with this gate.

Any change that breaks the AOT gate is a release blocker.

### 2. Performance is better with a static array

The source-generated `All` array is created once at class initialization and cached in a
`static readonly` field. Subsequent calls to `GetAll()` return the cached reference — O(1) with
zero allocations.

The reflection-based approach creates a new `List<T>` on every call (or requires additional
caching logic) and involves reflection overhead on first access.

### 3. The generated array is statically verifiable

Because the generator creates the array from the user's source-declared static members, the
set of values is determined at compile time. A developer reading the generated code can verify
exactly what `GetAll()` returns without running the program.

Reflection-based discovery is determined at runtime and can change if members are added to
subtypes in a loaded assembly — introducing subtle, hard-to-debug bugs.

### 4. Ardalis.SmartEnum's pattern is explicitly the anti-pattern here

`Ardalis.SmartEnum` represents the state of the art *before* Native AOT. Its approach was
reasonable in .NET Framework / .NET 5 era. For .NET 8+ with AOT-first design, the static array
generated at compile time is the correct approach.

---

## Alternatives Considered

| Alternative | Rejected because |
|-------------|-----------------|
| Reflection with `[DynamicallyAccessedMembers]` annotation | Prevents trimming but not IL3050. Still requires `RequiresDynamicCode` on the call site, breaking AOT. |
| Reflection only on non-AOT targets (`#if !ENABLE_NATIVE_AOT`) | Creates two code paths with different behavior. Testing complexity doubles. The value is low given that the source-generated array already solves the problem. |
| User-visible `RegisterAll()` registration method | Reflection-free, but requires the user to manually register values — worse DX than the generated array, defeats the purpose of the generator. |

---

## Consequences

- **Positive:** `GetAll()` / `.All` is AOT-safe, trimmer-safe, and verifiable at compile time.
- **Positive:** Performance is O(1) with zero allocation.
- **Negative:** If a user attempts to add SmartEnum members at runtime (via subclassing or
  dynamic code), those members will not appear in `GetAll()`. This is by design — SmartEnum
  members must be compile-time static.
- **Documentation action:** Documented in `docs/rejected-features.md`. The audit evidence
  (Ardalis reflection risk) is in `docs/competitive-evidence.md §8`.
