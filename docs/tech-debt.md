# Technical Debt Register

## Active Technical Debt

This document tracks known technical debt, its estimated cost, and the target version for resolution.
Per the v4.0 engineering specification, the number of active items here must not exceed 10.

> **Audit note (2026-08-10):** Items NEW-TD-A through NEW-TD-E were discovered during the comprehensive documentation audit. NEW-TD-E (CODEOWNERS) has already been resolved in the same session.

| TD-018 | **Newtonsoft.Json integration gap (GAP-002).** No `EricksonLopez.DomainPrimitives.NewtonsoftJson` package exists. Both Vogen and StronglyTypedId generate Newtonsoft.Json converters. This is an adoption blocker for enterprise .NET projects with Newtonsoft.Json dependencies. Tracked as a P1 gap in `docs/feature-gaps.md` (GAP-002) and formally planned in ADR-026. Package structure: separate NuGet project with optional dependency on `Newtonsoft.Json`; generator emits `JsonConverter<T>` for each primitive type; auto-registration via `AddDomainPrimitivesNewtonsoft()`. Note: the resulting package is **not AOT-compatible** (Newtonsoft.Json inherent limitation); must carry `[RequiresDynamicCode]` annotation. | 6h | v1.x | Open — scheduled for roadmap NOW-002 |
| NEW-TD-A | **`publish.yml` packs from nested paths that may not match the flat `src/` structure.** `publish.yml` uses paths like `src/dotnet-primitive-testing/EricksonLopez.DomainPrimitives.Testing/...` while the actual `src/` directory contains flat folders (e.g., `src/EricksonLopez.DomainPrimitives.Testing/`). If the subdirectory groupings (`dotnet-primitive-*`) do not exist, all 15 `dotnet pack` commands will fail silently or with a file-not-found error. **This must be verified before the first publish.** The workflow must not be modified until the project structure is confirmed. | 1h | v1.0.0 | ✅ Done — 2026-08-10 fixed publish.yml paths |

Resolution: after 1.0.0 is published, set `PackageValidationBaselineVersion=1.0.0` in props and remove the CI override. | 0.5h | v1.0.0 (post-publish) | ✅ Done — 2026-08-10 baseline removed for first release |
