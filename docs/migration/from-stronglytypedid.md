# Migrating from StronglyTypedId to DomainPrimitives

> **Version:** 2.0 | **Date:** 2026-08-10  
> **Difficulty:** Low  
> **Time estimate:** 30 minutes – 2 hours per project depending on size

---

## Should You Migrate?

StronglyTypedId is an excellent, narrow-focus library. DomainPrimitives is broader — it covers IDs, value objects, smart enums, and string/numeric primitives with a security-first design.

### Migrate if you need:
- **String/Numeric/Date primitives** beyond just IDs
- `IUtf8SpanParsable<T>`, `ISpanFormattable`, `IUtf8SpanFormattable` (not in STI)
- Declarative validation and normalization attributes
- ReDoS-resistant regex with security defaults
- Smart Enums (source-generated, AOT-safe)
- Multi-property Value Objects
- Auto-discovered EF Core / Dapper (no per-type configuration)

### Keep StronglyTypedId if you need:
- **Only** strongly typed IDs — nothing else (StronglyTypedId is simpler for that scenario)
- Custom backing types beyond `Guid/int/long/string`

## Attribute Equivalents

| StronglyTypedId | DomainPrimitives | Notes |
|:---|:---|:---|
| `[StronglyTypedId]` | `[StrongId<Guid>]` | Default backing type is Guid |
| `[StronglyTypedId(backingType: BackingType.Int)]` | `[StrongId<int>]` | |
| `[StronglyTypedId(backingType: BackingType.Long)]` | `[StrongId<long>]` | |
| `[StronglyTypedId(backingType: BackingType.String)]` | `[StrongId<string>]` | |
| `[StronglyTypedId(backingType: BackingType.NullableString)]` | N/A | Use `string?` in your model |
| `[StronglyTypedId(converters: StronglyTypedIdConverter.EfCore)]` | Auto-discovered | No annotation needed |
| `[StronglyTypedId(converters: StronglyTypedIdConverter.Dapper)]` | Auto-registered | No annotation needed |
| `[StronglyTypedId(converters: StronglyTypedIdConverter.NewtonsoftJson)]` | Supported via package | Use `EricksonLopez.DomainPrimitives.NewtonsoftJson` |

## Code Migration Examples

### Guid-backed ID

**StronglyTypedId:**
```csharp
[StronglyTypedId]
public partial struct OrderId;
```

**DomainPrimitives:**
```csharp
[StrongId<Guid>]
public readonly partial record struct OrderId;
```

Generated by both: `Create(Guid)`, `TryCreate(Guid, out result, out error)`, `Parse()`, `TryParse()`, `ToString()`, STJ converter, TypeConverter, EF Core ValueConverter, Dapper TypeHandler.

DomainPrimitives additionally generates: `ISpanParsable<T>`, `IUtf8SpanParsable<T>`, `ISpanFormattable`, `IUtf8SpanFormattable`, `TryFormat(Span<char>)`.

### New() factory for Guid-backed IDs

**StronglyTypedId:**
```csharp

```

```csharp

```

---

### Usage Pattern

**StronglyTypedId:**
```csharp
var id = OrderId.New();
var parsed = OrderId.Parse("3d7d4b7e-...");
var tryResult = OrderId.TryParse("3d7d4b7e-...", null, out var parsed2);
```

**DomainPrimitives:**
```csharp
var id = OrderId.New();
var parsed = OrderId.Parse("3d7d4b7e-...", null); // IParsable<T>
var tryResult = OrderId.TryParse("3d7d4b7e-...".AsSpan(), null, out var parsed2); // ISpanParsable<T>

// NET8+: Parse from UTF-8 bytes directly
ReadOnlySpan<byte> utf8 = "3d7d4b7e-..."u8;
var tryUtf8 = OrderId.TryParse(utf8, null, out var utf8Id); // IUtf8SpanParsable<T>
```

## Converter / Integration Migration

### EF Core

**StronglyTypedId (per-type converter annotation):**
```csharp
[StronglyTypedId(converters: StronglyTypedIdConverter.EfCore)]
public partial struct OrderId;

// DbContext — manual registration:
modelBuilder.Entity<Order>()
    .Property(o => o.Id)
    .HasConversion<OrderIdConverter>();
```

**DomainPrimitives (zero domain annotations, auto-discovered):**
```csharp
[StrongId<Guid>]
public readonly partial record struct OrderId; // No EFCore annotation needed

// DbContext — one-time setup discovers ALL domain types:
protected override void ConfigureConventions(ModelConfigurationBuilder configBuilder)
    => configBuilder.AddDomainPrimitivesConventions();
```

---

### Dapper

**StronglyTypedId:**
```csharp
[StronglyTypedId(converters: StronglyTypedIdConverter.Dapper)]
public partial struct OrderId;

// Registration:
SqlMapper.AddTypeHandler(new OrderIdTypeHandler());
```

**DomainPrimitives:**
```csharp
// One-time global registration of ALL handlers:
DomainPrimitivesDapperSetup.RegisterAll(Assembly.GetExecutingAssembly());
```

---

### ASP.NET Core / Route Parameters

**StronglyTypedId:**
```csharp
// Via TypeConverter (auto-registered)
app.MapGet("/orders/{id}", (OrderId id) => ...);
```

**DomainPrimitives:**
```csharp
// Via ModelBinder or TypeConverter (auto-registered via DomainPrimitives.AspNetCore)
app.MapGet("/orders/{id}", (OrderId id) => ...);
```

---

### System.Text.Json

Both generate `JsonConverter<T>` that registers automatically via `[JsonConverter]` on the type.

DomainPrimitives additional benefit: For string-backed IDs, the JSON deserializer reads directly from `Utf8JsonReader.ValueSpan` (NET8+) — no intermediate string allocation when the value fits in one buffer segment.

---

### Newtonsoft.Json

**StronglyTypedId:**
```csharp
[StronglyTypedId(converters: StronglyTypedIdConverter.NewtonsoftJson)]
public partial struct OrderId; // ✅ Supported
```

**DomainPrimitives:**
```csharp
// Install: EricksonLopez.DomainPrimitives.NewtonsoftJson
// Registration (at app startup or serializer configuration):
var settings = new JsonSerializerSettings().AddDomainPrimitives();
```

## Struct vs Partial Struct

**StronglyTypedId** uses `partial struct`.  
**DomainPrimitives** uses `readonly partial record struct`.

The `record struct` adds:
- Compiler-generated `==`/`!=`/`Equals()` based on value equality
- Compiler-generated `ToString()` (overridden by generator for clarity)
- Positional pattern matching support
- Better Deconstruct support

> **Migration action:** Change `partial struct` → `readonly partial record struct`.

## Search-and-Replace Cheatsheet

```
1. [StronglyTypedId]                       → [StrongId<Guid>]
2. [StronglyTypedId(backingType: BackingType.Int)]    → [StrongId<int>]
3. [StronglyTypedId(backingType: BackingType.Long)]   → [StrongId<long>]
4. [StronglyTypedId(backingType: BackingType.String)] → [StrongId<string>]
5. public partial struct                   → public readonly partial record struct
6. StronglyTypedIdConverter.EfCore         → (remove — auto-discovered)
7. StronglyTypedIdConverter.Dapper         → (remove — auto-registered)
8. new OrderId(guid)                       → OrderId.Create(guid)
9. OrderId.New()                           → OrderId.New() (same)
```
